# skill_read

> 真源：`crates/shell/yunyou-cli/src/skill_read.rs`。

按名读取一个技能的完整正文（目录里只列名字与描述；写插件/查能力等场景先读 plugins-seams）。只在本技能与当前任务相关时调用。

- **渐进披露链**：系统提示常驻技能目录（harness:skills 段，名+描述）→ 模型判相关 → skill_read 读全文进本轮。
- **容错**：不存在的技能名=人话报错+附当前可用清单；技能名守卫 `^[a-z][a-z0-9_-]*$`（无路径穿越面）。
- **折叠锚**：输出首行 `[skill:名]`——历史轮正文剥离策略卡（钩子缝）的识别锚。
- **双槽**：`<项目>/.yunyou/skills/` 优先 + `.dsh/skills/` 过渡兼容，同名项目槽胜。
