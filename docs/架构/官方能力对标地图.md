## 二、跨簇设计律（挖矿总纲）

1. **事件=真相**贯穿：会话/压缩/流式/计量全用同一套 append+replace+shadow-price 协议；
2. **capability seam 三角色**（Definition/Provider/Consumer）与三件拆分（seam+来源+消费）；
3. **能力阶梯**：模型只读自省<审批动态定义（重启即失）<持久 bundle；每个接口配「刻意排除清单」；
4. **引用经济学**：字节内容寻址落自家存储，事件/上下文只带引用（先持久化后引用）；
5. **轻重分离**：日志事件轻，重载荷 Host 服务按 seq 供数，不进模型请求（KV 零影响）；
6. **凭证与净化是配置面第一公民**：引用间接层+walk 脱敏+env 黑名单+坏条目不炸全局。
