## 一、模式枚举与转移表（未来落点：yunyou-agent-loop 或独立小模块）

```rust
/// 会话级模式态（不落 settings；随 session-meta 事件恢复——设计稿 §二）。
/// 与 claude types/permissions.ts:16-27 对齐，v1 只做四态。
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum SessionMode {
    Default,        // 全审批链生效
    AcceptEdits,    // fs 写类在工具自判层 Allow（复用 yun-suo 链做换 mode 试算）
    Plan,           // 写类工具模型面不可见（预设工具池层裁剪，非 Deny）
    Bypass,         // 跳过 L5 之后 ask（deny 规则+免疫层仍生效，yun-suo §一免疫层语义）
}

/// 模式转移：唯一入口纯函数（getNextPermissionMode 同构），UI/键位/工具共用。
/// 转移表（对应设计稿 §二；Err=非法转移）：
///   Default  -> Plan        需 EnterPlan 审批
///   Default  <-> AcceptEdits 显示层直切，无审批
///   Plan     -> Default|AcceptEdits  需 ExitPlan 审批（对象类型=文件审阅型）
///   任意     -> Bypass      需显式确认对话框；Bypass -> Default 由 killswitch 事件触发
pub enum ModeTransition { EnterPlan, ExitPlan { next: SessionMode }, ToggleAcceptEdits, EnterBypass, Killswitch }
pub type TransitionResult = Result<SessionMode, ModeTransitionError>;

## 二、预设 schema 类型（未来落点：yunyou-config；serde deny_unknown_fields）

```rust
/// settings.json "modes" 段（分源合并复用 task-5 分源缝；user < project < local）。
#[derive(serde::Deserialize)]
#[serde(deny_unknown_fields)]
pub struct ModesConfig {
    #[serde(default)]
    pub default_preset: Option<String>,
    #[serde(default)]
    pub presets: Vec<ModePreset>,
}

/// 预设=模式的配置打包（**不是**新状态机态——设计稿 §一要点①）。
#[derive(serde::Deserialize)]
#[serde(deny_unknown_fields)]
pub struct ModePreset {
    pub name: String,                 // 唯一键，default_preset 引用
    pub mode: SessionMode,            // 底层枚举（serde 小写 kebab）
    #[serde(default)]
    pub title: Option<String>,        // 显示名；缺省用 name
    #[serde(default)]
    pub symbol: Option<String>,       // 状态栏符号
    #[serde(default)]
    pub rule_overrides: RuleOverrides, // 追加语义：并进全局 permissions，deny 永远压顶
    #[serde(default)]
    pub auto_allow_sandboxed: bool,   // 总表 #6 沙箱自动放行缝
    #[serde(default)]
    pub tools: ToolPoolSpec,          // "*" | 显式名单（plan 预设=只读白名单+exit_plan）
}

#[derive(serde::Deserialize, Default)]
#[serde(deny_unknown_fields)]
pub struct RuleOverrides {
    #[serde(default)] pub allow: Vec<String>,
    #[serde(default)] pub ask: Vec<String>,
    #[serde(default)] pub deny: Vec<String>,
}

#[derive(serde::Deserialize)]
#[serde(untagged)]
pub enum ToolPoolSpec { All(String /* == "*" */), List(Vec<String>) }
```

## 三、与 yun-suo 缝的对表点（S1 抽验清单）

1. `GateContext` 需携带当前 `SessionMode`（或等价 mode 字段）——acceptEdits 换 mode 试算要靠它（设计稿 §三矩阵）；若没有则补构造函数参数，不改 trait 形状。
2. `GateDecision::Ask.suggestions` 的类型 `PermissionSuggestion` 需与本文档无关——plan 的 ExitPlan 走**文件审阅型**对象（对象类型注册缝），不经 PreToolUseGate；确认 yun-suo 侧「对象类型缝」枚举含 `FileReview { path }` 变体。
3. plan 态工具池裁剪发生在模型面（getTools 过滤，总表 #1 tools.ts:262-271 同构）——**不是**在 PreToolUseGate 里返回 Deny；抽验时确认两席对「模型面不可见 vs Deny 错误」口径一致。
4. Bypass 态语义对表：yun-suo §一免疫层不可触达——Bypass 只跳过 L5 之后 ask，免疫层（安全检查）照常命中。
