# 目录结构规范（开源门面达标批①，池 task-25）

> 2026-11-19 ｜ 承办 yun-shi ｜ 物理结构以仓库实态为准（总律②），本文是其规范表达；
> 结构变动须同批更新本文与《项目地图.md》。

## 顶层

| 路径 | 是什么 | 备注 |
| --- | --- | --- |
| `crates/` | 全部 Rust crate（按域分层，见下） | 工作区成员 |
| `sdk/` | 插件作者 SDK（yunyou-plugin-sdk+示例） | 插件作者唯一依赖面 |
| `docs/` | 全部文档（见下分目录） | 中文优先 |
| `.yunyou/` | 项目级技能/人设（skills/、persona.md、local/） | `local/` 不入库 |
| `config.example.toml` / `config.minimal.toml` | 示例配置（全量注解/最小三行） | 拷改即用 |
| `README.md` / `README.zh.md` | 项目门面（英/中） | 配置节与示例配置同源 |
| `ROADMAP.md` / `CONTRIBUTING.md` / `LICENSE` | 开源基建 | 内核不接受随意 PR |

## crates/ 分域（依赖单向：域内 → core → util）

| 子目录 | 域 | 代表 crate |
| --- | --- | --- |
| `core/` | 内核主板（装配/effect/fiber/config 校验）+ 主循环 | yunyou、yunyou-agent-loop |
| `infra/` | 配置与会话地基 | yunyou-config、yunyou-session |
| `tools/` | 工具域（注册表+内置工具+沙箱） | yunyou-tools、yunyou-retry |
| `shell/` | 宿主壳（CLI/渲染/装配/技能/记忆/命令） | yunyou-cli、yunyou-system-prompt、yunyou-commands |
| `team/` | 团队协作域 | yunyou-team、yunyou-team-worker-core |
| `plugins/` | 插件形态卡（protocol/SDK/策略卡） | yunyou-plugin-proto、yunyou-plugin-sdk、yunyou-permission、yunyou-tool-archive |
| `net/` | 网络面（gateway/web） | yunyou-gateway、yunyou-web |
| `llm/` | LLM 供面（openai 兼容端点） | yunyou-llm、yunyou-llm-openai |

## docs/ 分目录

| 子目录 | 放什么 |
| --- | --- |
| `接口/` | 机器可读契约（tools/commands/manifest/sandbox/message v1） |
| `架构/` | 架构方案与设计定稿（含 `架构/参照/` 取材报告——内部参照，不入开源库） |
| `设计/` | 单卡设计稿（任务书级；命名 `<主题>-<日期>.md`） |
| `需求/` | 业主需求原文与蓝图 |
| `tools/` | 每工具一份人读说明（与代码 description 同源单源） |
| `台账` | 项目状态.md（内部台账，不入开源库） |

## 运行时目录（约定，非仓库内容）

| 路径 | 是什么 |
| --- | --- |
| `~/.yunyou/` | yunyou-home（yunyou.toml、credentials.toml 0600、sessions/、projects/<项目>/memory/、skills/、AGENTS.md） |
| `<项目>/.yunyou/` | 项目级 skills/、persona.md、local/AGENTS.md（local 不入库） |
| `/etc/yunyou/AGENTS.md` | Managed 策略级人设（可选） |
