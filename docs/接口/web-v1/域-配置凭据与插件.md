# web.v1 域细则：settings / credentials / schedule / plugins / market / devices / system

> **状态**：**已冻结 v1.0（2026-11-19，lead 批）**。形状源：`yunyou-config` model.rs（DshConfig 九段）、`yunyou-credentials` settings.rs/redact.rs、`sdk/examples/scheduler`、manifest-v1 契约实测。
> 总则见 `规格.md`（§3 修订写、§4 secret 红线、§5 权限分级）。

## 1. settings 域（实施堵点③：修订写与 secret 纪律）

### 1.1 段清单（settings/sections，L1）

`{items:[{section,title,revision,entry:{kind:"settings"}|{kind:"plugin",pluginId}}]}`：

- 顶层段九个，按 DshConfig 实测冻结：`llm / session / system_prompt / tools / workspace / agent_loop / retry / credentials / sandbox`，另加 `plugins` 容器段与各插件段；
- 插件段经 manifest `ui:{kind:"settings",section}` 条目声明（manifest-v1 §3），投影服务按 config_schema 渲染，零界面代码；
- 未知插件 id 不报错（[plugins] flatten 语义），装配日志提示，不进 sections。

### 1.2 表单投影（settings/form，L1，payload `{section!}`）

`{section,revision,fields:[{path[],fieldType,title?,description?,value,default,options[],secret,required}],secrets:[{path[],set}]}`：

- fieldType 映射：string/number/integer/boolean/array/object（嵌套对象递归展平，array 停在自身——元素级投影二期）；
- **secret 纪律（红线）**：`secret:true` 字段 value/default 恒 null、required 恒 false（plainSchema 语义）；secrets sidecar 记全部 secret 槽位及 set 事实（set=false 也枚举，供「未配置」态）。`llm.api_key` 即首例（schema `role:"secret"`）。
- 每次投影必带 revision（规格 §3 单源计数器）。

### 1.3 写入（settings/write，L4，payload `{section!,revision!,value!}`）

- revision 相等 → 写入，响应 `{ok,revision:旧+1,applied:["即时生效"|"需重启"],restartRequired:bool}`；
- revision 不等 → `config/revision-conflict`，`details:{current}`，前端提示「配置已在别处更新」+重新加载（规范 §7.3）；
- 深度校验失败 → `config/validation`，`details:{keys:[非法键路径]}`（deny_unknown_fields 语义，拼写防呆）；
- secret 字段写入走 §2 credentials/set 或在 value 中提交——服务端定点改写为引用或入托管存储，**响应与后续投影零明文**；
- 生效语义（applied 逐段如实）：沙箱 network_denied 重启生效（非热调）；volatile 热编辑面一期不做（投影侧预留位），全段缺省「需重启」，实测可热生效的段落名后补。

## 2. credentials 域

### 2.1 目录（credentials/list，L1）

`{storePath, items:[{path[],set,reference?,source:"env"|"store"|"file"}]}`：

- `reference` = 引用形态（如 `$YUNYOU_LLM_API_KEY`）；只写事实（已配置/引用来源/store 路径），**零明文**；
- **【裁决②，lead 2026-11-19】`source` 三值投影采纳**：`env`（环境变量覆盖，永不读出值只标来源）/`store`（托管存储）/`file`（配置文件明文，迁移兼容）——否则用户「已 set 却未生效」必困惑；env 覆盖优先级事实照 config：env > store > file；
- store 文件 `<yunyou-home>/credentials.toml`（600 权限，装配补值）。

### 2.2 写入与删除

- `credentials/set`（L4）payload `{path[],value!}` → `{set:true}`；值只进托管存储或触发定点改写（迁移语义：明文配置启动迁移入托管+改引用）；尝试读回 → `credentials/write-only` 恒拒绝。
- `credentials/delete`（L3）payload `{path[]}` → `{deleted:true}`；前端二次确认。
- 环境变量覆盖优先级照 config 事实：env（如 `DSH_TEST_LLM_API_KEY`）> 托管存储 > 配置文件明文（迁移兼容）；投影标注覆盖来源，env 值永不读出。

## 3. schedule 域（三选一必填恰一；回显即确认）

| 方法 | payload | 响应 |
| --- | --- | --- |
| schedule/create (L2) | `{at_ms?|every_minutes?|cron?三选一, message!, durable?}` | `{id,nextFireMs,nowMs,message,durable,note}` |
| schedule/list (L1) | `{}` | `{entries:[{id,spec,nextFireMs,message}],nowMs}` |
| schedule/delete (L3) | `{id!}` | `{deleted:id}`；不存在 → `schedule/unknown-id`，details.entries 列现有 id |

纪律（设计 §四原文冻结）：

1. 创建前前端先经 `system/info`/time 获知当前时间，`nextFireMs` 回显即确认（用户复述下次触发与注入消息全文）；
2. `every_minutes < 5` → `schedule/spec`（防过密循环打爆会话）；cron=5 段标准子集（分 时 日 月 周）；
3. **durable 语义诚实**：真投递缝与持久化随 proto v1.1，v1 投影一律「会话内有效」，不给跨重启开关（L5）；durable=true 创建请求服务端留痕（stderr/日志）并在响应 note 提示「须用户明说」；
4. 到期投递回执 `schedule/fired` 事件随投递缝开闸（websocket.md §4），未开闸前不发送。

## 4. plugins 域

### 4.1 目录（plugins/list，L1）

`{items:[{id,version,level:"bundled"|"market",contracts[],provides[],inject[],ui[],autoEnable,enabled,configRevision}]}`：

- 形状=PluginManifest 九字段投影（config_schema 不入 manifest，经 settings/form 段投影取）；
- enabled=配置 enable ?? manifest.auto_enable；未列出的插件按 auto_enable 处理。

### 4.2 工具与运行态（plugins/tools，L1，payload `{pluginId!}`）

`{items:[{name,description,parametersSchema?,source:"bundled"|"proto"|"sdk"}],status:{running:boolean,errors[]}}`：proto 插件工具经握手 ToolsList 投影；未运行插件=空 items+status 如实。**【裁决③，lead 2026-11-19】errors 人话口径**：「插件 <id> 未运行：查看启动日志（yunyou web 加 --verbose 重启可看装载失败原因）」——具体措辞云络落码时定稿，语义不得变。

### 4.3 启停与配置（L3，均带 revision）

- `plugins/enable` payload `{pluginId!,enable!,revision!}`；启停破坏性操作前端二次确认；
- `plugins/config` payload `{pluginId!,revision!,config?}`（config 省略=读）；
- 装载时序语义：写入落配置，装载/拒装结果经 `config/reloaded` 事件与下次 list 反映；ui kind=page 拒装（`plugin/ui-page-rejected`，manifest-v1 §3）。

## 5. market 域（[后续]，只定占位语义）

- 本地插件管理先行，不引入 DSH 账号市场（规范 §2.3）；
- `market/list` / `market/install` 为 [后续] 占位：开闸条件=⑨工作区授权（S11 Landlock+seccomp）+②bundle 补丁缝；
- 开闸前调用一律 `plugin/restricted`；market 插件 MVP 权限面：`network=false`、`credentials=[]` 恒禁；
- 热更新、插件工具取消、凭据获取：协议未开闸，不留假开关（capabilities/list 以 gate 标注）。

## 6. devices / system 域（收尾）

- `system/info`（L1）→ `{version,contract:"web.v1",model,workspaceRoot,sessionDir,startedAt,nowMs}`；关于页版本/许可走静态资产，不入接口。
- `system/health`（L1）→ `{ok:true,uptimeMs,turnOpen}`。
- `devices/current`（L1）→ `{connected,via:"query"|"bearer"|"cookie",loopback}`；令牌属 secret 红线：无读回、无枚举、无多设备清单（后续批再议）。
- 非回环启动时 loopback=false，前端提示外泄风险（server.rs 既定行为）。

## 7. 对表点裁决记录（lead 2026-11-19 终审裁决，已回写正文）

1. 【裁决①】applied/restartRequired 生效语义逐段表**够用**：W5 按此实施，现态全段「需重启」诚实兜底获认可（§1.3 维持）。
2. 【裁决②】env 覆盖来源采纳进 credentials/list：`source:"env"|"store"|"file"` 三值投影（§2.1 已回写）；env 永不读出值只标来源。
3. 【裁决③】status.errors 人话口径定稿（§4.2 已回写）：「插件 <id> 未运行：查看启动日志（yunyou web 加 --verbose 重启可看装载失败原因）」，措辞云络落码时可润、语义不得变。
