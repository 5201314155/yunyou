## 1. ToolDefinition trait（九方法）

| 方法 | 签名 | 契约语义 | 默认值 |
| --- | --- | --- | --- |
| `name` | `→ &str` | 工具名（模型可见；建议 snake_case） | 必须实现 |
| `description` | `→ &str` | 工具描述（模型可见，注入系统提示词） | 必须实现 |
| `parameters` | `→ Value` | 参数 JSON Schema（draft 2020-12；object 类型）；模型给出的 args 由工具自行校验/收窄 | 必须实现 |
| `output_schema` | `→ Option<Value>` | canonical 输出声明；**S4 收敛声明：新工具必须覆盖**（存量 bash 暂缺=豁免中，v2 连同 register 拒 `None` 一并收紧——rustdoc 文本断言 CI 化防悄悄改） | `None`（存量豁免） |
| `timeout_ms` | `→ Option<u64>` | 单次调用超时毫秒；`None`=用全局 `tool_timeout_secs`。**绝不进模型面** | `None` |
| `is_concurrency_safe` | `→ bool` | 是否可并发执行；默认 false=保守串行，读类工具显式选入 true。调用方不得假定未声明者并发安全。**绝不进模型面** | `false` |
| `render` | `(&ToolOutcome) → String` | 执行结果→人/卡片可见文本（纯投影）；canonical 值不受影响 | 统一渲染 `render_outcome` |
| `presentation_meta` | `→ Option<PresentationMeta>` | 卡片元数据（title/summary/icon），**静态纯声明不含运行期值**——渲染层执行时喂 args/outcome 插值 | `None` |
| `execute` | `(args, ToolExec) → BoxFut<ToolOutcome>` | 执行一次调用；必须 `Send + Sync` 且返回 `'static` future | 必须实现 |

## 2. 白名单纪律（模型面，评审线一强制）

`RegistryService::schemas()` 只投 **name/description/parameters 三元组**——`timeout_ms`/`is_concurrency_safe`/`presentation_meta` 的键与值**零出现**（键集合锁死＋探针特征值值级双断言，测试场景一：超时值 99999/卡片文案/渲染串均不得泄漏进模型面）。官方同构：`contracts.ts:74-77`「NEVER sent to the model」。

## 3. ToolExec / ToolOutcome / ToolError

```rust
pub struct ToolExec {
    pub call_id: String,                      // 会话 tool_call/tool_result 事件关联键
    pub cancel: CancellationToken,            // 取消令牌；工具长任务必须观察（取消语义：
                                              //   等工具 future 静止不 abandon，对齐官方
                                              //   contracts.ts:32-46 settle-after-quiescence）
    pub workspace: Option<WorkspaceContext>,  // 契约⑨策略对象槽位（一期落位不读；
                                              //   sandbox.v1 落地时充实——槽位已预留防返工）
}
pub enum ToolOutcome {
    Ok(serde_json::Value),   // 成功：canonical 无损 JSON（lossless）
    Err(ToolError),          // 业务失败：进会话 tool_result，is_error=true
}
pub struct ToolError {
    pub code: String,        // 稳定错误码（§6）
    pub message: String,     // 中文可读信息
    pub hint: Option<String> // 下一步指引：中文/可执行/不含内部路径；渲染时追加「提示：」行
}
```

**hint 的 serde 兼容（v1→v1.1 加法演进，测试场景六锁死）**：旧数据缺 hint 可读回落 `None`（serde default）；新数据带 hint 往返无损；显式 `null` 同回落。收紧为 deny_unknown_fields、去 default、或改 hint 形态均在此红——「规格悄悄改」防线的 CI 化。

## 4. 渲染钩（契约⑥）

- 默认 `render`＝`render_outcome`：`Ok(value)`→pretty JSON；`Err(err)`→`render_error`（`[错误 <code>] <message>`，有 hint 追加 `\n提示：<hint>`）。
- per-tool 可覆盖定制（纯投影）；示范=grep 平铺（matches 逐行）与「（无匹配）」空态提示——canonical 值不变（模型面无损）。
- `presentation_meta` **不做成 ToolOutcome 伴随字段**：挂 Definition 与 timeout_ms 同构；塞进结果值会把展示负载污染 canonical 数据通路与会话日志（「事件轻、重载荷不进模型请求」纪律）。

## 5. 注册面（契约①）

`ToolsRegistry::register(tool) → Disposer`：同名拒绝（`ServiceDuplicate`）；注册即挂 fiber effect，卸载逆序注销；注册后 per-tool 声明（timeout_ms 等）经注册表访问器即时可见（渲染/调度侧通道；未注册名回落保守值）。

**跨插件注册缝（K-7/任务26 T2，2026-11-16 加法）**：`RegistryService::register_tool(self: Arc<Self>, tool) → Disposer`——trait 面的注册入口，供持有 `Arc<dyn RegistryService>` 的插件（如团队插件注册 spawn_teammate/team_task_* 工具族）在无具体类型处注册；`Arc<Self>` 接收器=dyn 兼容（`&Arc<Self>` 破坏 dyn），实现委托既有固有 `register`（Weak 撤销器语义零改动，名字取 `register_tool` 不遮蔽固有版——既有调用点含 S4 冻结测试）。**只读视图例外**：包装型注册表（如成员工具面的 deny+override 视图）实现为 `Err` 拒绝——注册是写操作，只读视图不越权，工具面收敛在提供方一侧。

## 6. 稳定错误码表（2026-11-14 全树实测 16 码）

| 域 | 错误码 |
| --- | --- |
| 路径/IO | `tool/path-outside-root`、`tool/io`、`tool/not-found`、`tool/ambiguous`、`tool/binary`、`tool/too-large` |
| 参数 | `tool/args`、`tool/regex`、`tool/glob` |
| 执行 | `tool/timeout`、`tool/cancelled`、`tool/spawn`、`tool/wait`、`tool/panic` |
| 兜底/无果 | `tool/unknown`、`tool/no-match` |
| 补丁解析（apply_patch） | `tool/patch-syntax`、`tool/patch-hunk`、`tool/patch-empty`、`tool/patch-line`、`tool/patch-context` |

规范：稳定码格式 `tool/<域-动作>`；新码=v1 加法演进（serde 无损）；错误信息中文；hint 可执行不含内部路径。新增错误码不破契约；改既有码语义=v2。
