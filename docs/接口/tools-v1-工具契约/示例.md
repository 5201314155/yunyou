# tools.v1 契约示例

> 配套 `规格.md`。示例取自规格冻结测试的真实形态（tests/工具契约规格冻结.rs），可作工具作者模板。

## 示例 1：全量覆盖工具模板（新工具照此，五点全覆盖）

```rust
use std::sync::Arc;
use yunyou_tools::contract::{PresentationMeta, ToolDefinition, ToolExec, ToolOutcome};
use yunyou_util::BoxFut;

struct WeatherTool;

impl ToolDefinition for WeatherTool {
    fn name(&self) -> &str { "weather" }
    fn description(&self) -> &str { "查询城市当前天气" }
    fn parameters(&self) -> serde_json::Value {
        serde_json::json!({
            "type": "object",
            "required": ["city"],
            "properties": { "city": { "type": "string" } }
        })
    }
    // S4 收敛纪律：新工具必须覆盖（不覆盖=评审打回项）
    fn output_schema(&self) -> Option<serde_json::Value> {
        Some(serde_json::json!({
            "type": "object",
            "properties": { "temp_c": {"type": "number"}, "desc": {"type": "string"} }
        }))
    }
    fn timeout_ms(&self) -> Option<u64> { Some(5_000) }        // 不进模型面
    fn is_concurrency_safe(&self) -> bool { true }             // 只读=可显式选入；不进模型面
    fn presentation_meta(&self) -> Option<PresentationMeta> {
        Some(PresentationMeta::new("天气", "查询 city 的天气", "weather")) // 静态声明
    }
    fn execute(&self, args: serde_json::Value, exec: ToolExec) -> BoxFut<'static, ToolOutcome> {
        Box::pin(async move {
            // 参数自行校验/收窄；长任务必须观察 exec.cancel
            let Some(city) = args.get("city").and_then(|v| v.as_str()) else {
                return ToolOutcome::err_h("tool/args", "缺少 city 参数", "请求参数需含 city 字符串");
            };
            ToolOutcome::ok(serde_json::json!({ "temp_c": 21.5, "desc": format!("{city}：多云") }))
        })
    }
}
```

## 示例 2：最小工具（四件套；新钩子全走安全默认）

```rust
impl ToolDefinition for MinimalTool {
    fn name(&self) -> &str { "minimal" }
    fn description(&self) -> &str { "最小实现" }
    fn parameters(&self) -> serde_json::Value { serde_json::json!({"type": "object"}) }
    fn execute(&self, _args: serde_json::Value, _exec: ToolExec) -> BoxFut<'static, ToolOutcome> {
        Box::pin(async { ToolOutcome::ok(serde_json::json!({"ok": true})) })
    }
}
// 默认：output_schema=None（存量豁免）/ 超时=全局 / 串行 / 无卡片 / 统一渲染
```

## 示例 3：ToolOutcome / ToolError JSON（serde 冻结面）

```jsonc
// 成功：canonical 无损 JSON 值
{"ok": true}

// 业务失败（v1，无 hint）——旧数据/网关留存形态，必须可读
{"code": "tool/path-outside-root", "message": "路径越界：/etc/hosts 不在工作区内"}

// 业务失败（v1.1，带 hint）——往返无损；显式 null 同回落 None
{"code": "tool/path-outside-root", "message": "路径越界：/etc/hosts 不在工作区内",
 "hint": "改用工作区内相对路径，或 write 工具写入已授权目录"}
```

## 示例 4：会话可见文本（render_error 渲染形态）

## 示例 7：注册与注销（契约①）

```rust
let registry = ToolsRegistry::new();
let disposer = registry.register(Arc::new(WeatherTool))?;  // 同名拒绝 ServiceDuplicate
// disposer 随 fiber effect 卸载逆序注销；注册后元数据经注册表访问器可见：
registry.timeout_ms("weather");            // Some(5000)
registry.presentation_meta("weather");     // Some(卡片声明)
registry.timeout_ms("ghost");              // None（未注册名回落保守值）
```
