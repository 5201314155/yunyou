## 1. 定位与威胁模型

防「工具**造出的子进程**干坏事」（越界写/越权网络/提权逃逸，进程外）；与崩溃隔离（任务27，防进程内烂码）正交互补。四层阶梯：

| 层 | 机制 | 职责 |
| --- | --- | --- |
| L0 | path_guard（既有） | 进程内文件工具路径门禁 |
| L1 | bash_guard 文本门禁（既有） | 毫秒级快筛+hint 指路（可教学） |
| L2 | workspace 授权快照（本契约） | 策略 Arc 快照单源贯穿，先授权后执行 |
| L3 | 内核沙箱（本契约） | Landlock 写限制+seccomp 网络禁断，内核裁决不可绕 |
| L4 | 二期加固 | bwrap 读遮盖/网络代理/审批链 |

铁律：**宿主进程自身绝不设限**（否则 LLM 中转/会话落盘全炸）；Landlock/seccomp 只上工具子进程。

## 2. 策略对象 WorkspacePolicy v1（三字段冻结）

```rust
/// 策略快照（构造一次，Arc 贯穿 L2/L3，防两处解析漂移）
pub struct WorkspacePolicy {
    /// 可写根集合（全部 canonicalize 后绝对路径；含 workspace root）
    pub writable_roots: Vec<PathBuf>,
    /// 出网许可；v1 恒 false（枚举留位：二期 NetworkMode::{Denied, Proxy}）
    pub network_access: bool,
    /// 策略语义版本（helper 校验不识别即拒）；v1 = 1
    pub policy_version: u32,
}
```

- **可写根构造**（yunyou-sandbox 插件侧）：`[workspace root, /dev/null, /tmp?, TMPDIR?]`；`writable_tmp=false` 时去掉 /tmp/TMPDIR（/tmp 默认并入的硬理由：bash pwd 捕获临时文件与编译器临时文件落 `std::env::temp_dir()`）。
- **读=全盘**（ruleset 只 add read `/`）：工具链合法性硬约束（cargo/rustc/系统库//proc//etc/ssl）；读白名单=维护工具链根清单且路径漂移即坏，误伤代价高于收益（TS 版官方 Landlock 档同 `readOnly: ['/']`，profiles.ts:26-31，经云堑设计实测引）。**越界读残余风险明示**：一期可读敏感文件，读遮盖归二期（bwrap tmpfs 盖敏感路径——Landlock 纯 allow-list 表达不了读拒名单）。
- **先授权后执行**：策略在 spawn 前构建成不可变 PreparedSandbox，执行期无二次路径解析（契约⑨「路径映射原子校验」的最小形态）。

## 3. SandboxEnforcer trait（契约面签名）

```rust
/// 沙箱执行器（契约面落 yunyou-tools；实现落 yunyou-sandbox 插件，依赖方向单向）
pub trait SandboxEnforcer: Send + Sync {
    /// 策略 → helper spawn 参数集（策略 JSON/命令 cwd/argv 分隔语义）。
    /// 失败=io::Err（含 NotEnforced：内核无 Landlock 必须 fail-closed 拒执行）。
    fn prepare(&self, policy: &WorkspacePolicy) -> std::io::Result<PreparedSandbox>;
}
```

- 服务键：`dyn SandboxEnforcer`；插件 manifest：`contracts: ["sandbox.v1"]`，`provides: ["dyn SandboxEnforcer"]`，`level: bundled`。
- **可选消费不进 inject**（形态裁决）：消费方 `ctx.get::<dyn SandboxEnforcer>()`——inject 强依赖=禁用沙箱插件连带瘫痪工具面（epoch 语义「依赖消失即卸载」）；可选 get+降级告警把选择权留给策略而非装配事故。
- 服务对象=**进程类工具**（一期唯一 bash）；文件类工具在宿主进程内直接 IO，L0 已守，不接沙箱。

## 4. 卡面配置（yunyou-sandbox）

| 配置键 | 默认 | 语义 |
| --- | --- | --- |
| `[sandbox] enabled` | true | 显式降级开关（**volatile 热调**）；false=直跑+warn 日志+结果 meta 标注 `unsandboxed` |
| `[sandbox] writable_tmp` | true | /tmp 与 TMPDIR 是否入可写根 |
| `[sandbox] network_denied` | true | 网络禁断；**改配置重启生效不热调**（运行中放开网络=安全面突变） |

## 5. Linux 后端语义（一期单后端；失败面全显式）

- **Landlock 写限制**：`read "/"` + `read_write 可写根` + NNP；规则按目录层级绑定（workspace 内新文件自动受控）；每次 spawn 重新 canonicalize（防目录 mv 后规则漂移）。**NotEnforced 检测=fail-closed 硬门**：内核 <5.13 必须拒执行（`tool/sandbox-failed`），绝不静默裸跑。
- **seccomp 网络禁断**（deny-list 抗 libc 演进）：connect/accept/bind/listen/sendto 等网络主面全族 deny；socket/socketpair 仅放行 AF_UNIX（cargo/git 子进程管理合法面）；io_uring 三 syscall deny（堵 socket 旁路）；ptrace/process_vm_* deny（防反向篡改宿主）。前置 `PR_SET_NO_NEW_PRIVS`（兼防 setuid 提权）。
- **helper=arg0 自唤起**：parent spawn `current_exe` 绝对路径+argv[0] 哨兵名+`--policy-json`+`--`+用户命令；helper 应用沙箱后 execvp 换映像（PID 不变，退出码/信号天然透传）；pre-main 加固三件套（`PR_SET_DUMPABLE=0`+`RLIMIT_CORE=0`+清洗 `LD_*`）。

失败面四态（全部显式无静默）：enforcer 缺失→直跑+warn+meta `sandboxed:false`（唯一受控降级路）；helper 应用失败→`tool/sandbox-failed` 拒执行不回退裸跑；current_exe 不可得→同上；用户命令被内核拒→EACCES/EPERM/SIGSYS 原样透传。

## 6. 模型告知段（经契约③ section 缝；诚实律）

yunyou-sandbox setup 时 `register_section` 贡献「沙箱执行环境」提示段，disposer 随卸载注销。**告知面与执行面同源**：仅沙箱实际生效（enabled=true 且 enforcer 在位）时注册；降级/卸载不注册（模型面绝不允许描述与真实执行不符的行为，宁缺勿谎）。文案四条事实面：可写范围+改道指引／无网络+预期行为声明／权限拒绝≠故障（堵换写法试错）／正常开发不受影响。**不写**实现名词（landlock/seccomp 是噪音）；**不提**临时目录可写（与 L1 门禁表面矛盾）。

## 7. 验收与已知合法破坏面

混沌矩阵（越界写/越权网络/绕过尝试/降级失败/告知面三态/回归）全表绿=S11 验收口径，全表见权威设计 §8。**一期合法破坏面明示**（防「沙箱坏了」误报）：

| 场景 | 表现 | 定性 |
| --- | --- | --- |
| cargo/git 拉新依赖 | connect 被拒 | 预期行为；二期 managed-proxy 解决 |
